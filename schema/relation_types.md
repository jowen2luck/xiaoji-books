# Relation Types 关系类型定义

知识引擎中所有 Knowledge Object 之间的关系类型，按语义分组。

## 一、概念-概念关系 (Concept → Concept)

| 类型 | 语义 | 示例 |
|------|------|------|
| Defines | A 定义了 B | 商品 → 使用价值 |
| DependsOn | A 成立依赖 B | 剩余价值 → 劳动价值论 |
| Explains | A 解释了 B | 劳动二重性 → 商品二因素 |
| IsA | A 是 B 的一种 | 货币 → 一般等价物 |
| PartOf | A 是 B 的一部分 | 可变资本 → 资本 |
| ExampleOf | A 是 B 的例子 | 圈地运动 → 原始积累 |
| Prerequisite | A 是 B 的前提 | 劳动 → 价值 |
| Opposes | A 与 B 对立 | 使用价值 ↔ 交换价值 |
| RelatedTo | A 与 B 相关（弱） | 异化 → 拜物教 |

## 二、论断-论断关系 (Claim → Claim)

| 类型 | 语义 | 示例 |
|------|------|------|
| Supports | A 支持 B | 利润率下降 → 危机必然性 |
| Criticizes | A 批评 B | 伯恩施坦 → 革命理论 |
| Develops | A 发展了 B | 列宁帝国主义论 → 马克思资本论 |
| Contradicts | A 与 B 矛盾 | 和平过渡 ↔ 暴力革命 |
| Refutes | A 驳斥了 B | … |
| EvidenceOf | A 是 B 的证据 | 1929大萧条 → 生产过剩理论 |
| ApplicationOf | A 将 B 应用到 | 毛泽东农村包围城市 → 暴力革命 |

## 三、历史关系 (Temporal / Historical)

| 类型 | 语义 | 示例 |
|------|------|------|
| HistoricalOrigin | A 来源于 B | 科学社会主义 → 空想社会主义 |
| InfluencedBy | A 受 B 影响 | 列宁 → 马克思 |
| Influenced | A 影响了 B | 巴黎公社 → 十月革命 |
| PrecededBy | A 之前是 B | 马克思主义 → 青年黑格尔派 |
| SucceededBy | A 之后演变为 B | 第一国际 → 第二国际 |
| ContemporaryWith | A 与 B 同时期 | 卢森堡 → 列宁 |

## 四、人物-理论关系 (Person ↔ Concept/Claim)

| 类型 | 语义 | 示例 |
|------|------|------|
| AuthoredBy | A 由 B 提出 | 剩余价值理论 → 马克思 |
| ParticipatedIn | A 参与了 B | 列宁 → 十月革命 |
| OpposedBy | A 被 B 反对 | 暴力革命 → 伯恩施坦 |
| LedTo | A 导致了 B | 二月革命 → 十月革命 |
| Witnessed | A 见证了 B | … |
